## 原因与处理

1. 本轮开始时 MS2130 已被系统正确识别。先停止本地文件演示并确认进程退出，释放设备后再启动实时程序。
2. 电脑 API 当前只返回一个活动主显示器。原播放器要求一个独立活动外接显示器，因此报 `Expected one active external display; found 0`。
3. 尝试扩展显示后，该 API 的返回仍未满足原播放器要求。实测计时标记可以传到采集端，因此新增兼容当前主屏输出方式的播放器，没有继续反复改线或重烧 FPGA。
4. 新播放器在当前活动显示器上全屏播放官方视频，保持视频宽高比；没有修改电脑显示分辨率或刷新率。报告中的电脑逻辑显示模式为 2560×1600、120 Hz，不能拿它当作 FPGA 实际 HDMI 输入时序的测量结果。
5. 香橙派通过既有停车保护启动流程重新协商视频模式，各模式均连续取得 24 帧有效图像后，再启动原实时程序。
