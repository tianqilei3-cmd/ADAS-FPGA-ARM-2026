# ARM端完整运行包与香橙派桌面入口

日期：2026-11-01。本包用于当前 Orange Pi 3B / RK3566，保留已实机验证的红停、绿行和强行报警基线。电脑用于播放HDMI视频、SSH和FPGA下载；识别计算在香橙派本机完成。

## 现在怎么运行

队友电脑不需要安装YOLO、PyTorch、Anaconda或训练环境。当前这块香橙派的运行环境已经安装，11月1日再次校验64份源码、15个模型，全部哈希一致。还在禁止导入torch/torchvision/ultralytics的条件下成功导入了主程序。

香橙派Linux桌面现有三个快捷方式：

- **ADAS 道路演示**：核对版本、模型、依赖和设备，调用已验证的启动预检，再进入画面。双击后会有终端显示状态，启动稍有等待。
- **ADAS 停止演示**：请求当前固定目录的演示程序正常退出，释放视频和串口；不结束其他版本的程序。
- **ADAS 运行诊断**：显示文件、依赖、设备、空间和进程检查，按回车关闭。诊断不会占用视频/UART，也不会代替实际视频和按键验收。

演示画面按Q或Esc也可退出。重复点击启动会被阻止，避免多个程序争用NPU、视频和串口。

没有快捷方式时，也可以在香橙派终端直接运行原入口：

```sh
sh /home/orangepi/adas2026/signal_recovered_20261028/START_SIGNAL.sh
```

SSH远程启动桌面入口（需电脑与香橙派网络互通，并使用自己有权限的登录方式）：

```sh
ssh orangepi@172.20.10.6
python3 /home/orangepi/.local/share/adas2026/desktop_20261101/adas_launcher.py start
```

这里的IP为11月1日实际连通的地址；换网络后以香橙派当前IP为准。SSH只用于启动，画面出现在香橙派HDMI连接的显示器，不会自动传回电脑窗口。本包不包含登录私钥、密码或账号token。

## 接线和启动顺序

```text
电脑HDMI输出 → 盘古HDMI IN
盘古HDMI OUT → HDMI采集卡 → 香橙派USB3
香橙派HDMI输出 → 独立显示器
香橙派USB → 盘古CP2102 USB-UART
电脑USB → 下载器 → 盘古JTAG（用于FPGA下载）
```

1. 板卡正常上电，香橙派登录Linux桌面。
2. FPGA需要匹配的0x29固件（反馈build_tag=41）。本包不自动下载FPGA、不改写Flash；若队友已换新固件，请先核对接口兼容，不覆盖队友工程。
3. 电脑HDMI输出1920×1080/60Hz，在连接盘古的输出上全屏播放道路视频；播放器确实处于播放状态。只有桌面、黑屏或未播放的视频，不算道路输入。
4. 双击“ADAS 道路演示”。预检先停车，分别等待分屏和全幅各24个连续有效帧。没有视频或版本不匹配时会显示错误并结束，不伪造成功画面。
5. 看到道路画面和UART确认后，先确认signal/straight/stop，再按实体键测试。

KEY2切换场景；KEY3/4/5为左/直/右意图；KEY6切换行驶请求与停车；KEY7切换强行请求。第二行go是驾驶请求，第一行GO/STOP是实际判断。红灯下请求go仍应STOP；强行红灯应STOP、ALARM1。

LED4是停车/报警综合灯，普通红停时也可能亮，报警要看ALARM数字和反馈。运行期间保持线缆和供电稳定。

## 包内文件

- `runtime/`：64份冻结源码、manifest、15个可直接用于原环境的RKNN/ONNX模型、已验证的预检启动程序和START_SIGNAL.sh。运行无需训练用PT权重。
- `launcher/`：桌面启动、停止、诊断及安装器。
- `reference/`：最新安装和诊断记录、工程验收记录、10月29日补训结果、版本与接口限制说明。
- `reference/FPGA_0x29_test_ddr.sbit`：与当前ARM基线匹配的历史固件，SHA由整包清单校验；仅供队友核对和手动恢复，不自动下载、不覆盖新工程或写Flash。
- `MANIFEST.json`、`verify_package.py`：本包文件SHA与独立核验入口。
- `INSTALL_ON_ORANGEPI.sh`：在香橙派安装/恢复快捷方式。

当前运行目录已经存在且校验通过时，安装器只更新小型快捷方式工具，不重复复制模型。先确认本机已有快捷方式，通常无需再往香橙派复制整包。

需要恢复时，将完整压缩包解压到U盘或其他目录，在香橙派终端进入解压后的`ARM_run_20261101`：

```sh
python3 verify_package.py
sh INSTALL_ON_ORANGEPI.sh
```

安装器只支持当前orangepi用户和固定目标目录；已有运行目录会完整校验，版本不同则停止，保留现有改动。只有运行目录完全不存在时才从本包恢复。不要使用sudo运行安装器。

新系统还需要匹配的Linux桌面、RKNNLite/NPU驱动、Python3、OpenCV、NumPy和ONNX Runtime。本包是程序与模型备份，不含系统镜像；重刷系统后不能仅凭解压本包保证运行。
